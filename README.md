# ZimaOS Login Demo

Minimal single-file Go demo packaged as a systemd-sysext raw image.

## Defaults

- Module name: `zimaos-login-demo`
- Installed version in raw manifest: `v1.0.0`
- Target version API response: `v1.0.1`
- API port: `49321`
- API and WebSocket prefix: `/v2/api/rt`
- Frontend entry: `/modules/zimaos-login-demo/index.html`
- Demo credentials: `admin` / `zimaos`
- Backend source: `main.go` using `github.com/go-chi/chi/v5`
- Frontend source: `web/src/` with Vite, SolidJS 2.0 beta, and TailwindCSS

## API

- `GET /v2/api/rt/healthz`
- `POST /v2/api/rt/login`
- `GET /v2/api/rt/target-version`
- `GET /v2/api/rt/ws` WebSocket echo endpoint

On startup, the backend tries to register this route with `casaos-gateway` by reading `/var/run/casaos/management.url`:

```json
{"path":"/v2/api/rt","target":"http://127.0.0.1:49321"}
```

Example:

```bash
curl -s http://127.0.0.1:49321/v2/api/rt/target-version
curl -s -X POST http://127.0.0.1:49321/v2/api/rt/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"zimaos"}'
```

The frontend loads `/modules/zimaos-login-demo/config.js`, which is generated by `scripts/build-raw.sh` with the local module version. The module reads Zima WebUI tokens from `localStorage`; if a deployed module path has no access token, it redirects to the WebUI login route and asks it to return to the current URL.

## Build

```bash
bun install
make test
bun run dev
make build
make raw
```

Deploy to a ZimaOS box and verify the mounted `/usr` tree:

```bash
scripts/deploy-to-zima.sh 10.0.0.85
```

The deploy script checks that `/usr/share/casaos/www/modules/zimaos-login-demo/config.js` is available after `systemd-sysext refresh`.

`make raw` requires `mksquashfs` from `squashfs-tools`. It creates:

```text
zimaos-login-demo.raw
```

## Source Layout

`web/src/` contains the frontend source. `bun run build` writes local generated files to ignored `web/static/`. `make raw` builds the frontend with Bun directly into a temporary raw root, then stages `config.js`, the CasaOS manifest, and the Go binary before creating the raw image.

```text
main.go
web/index.html
web/src/App.tsx
web/src/auth.ts
web/src/api.ts
raw/usr/lib/systemd/system/zimaos-login-demo.service
raw/usr/lib/extension-release.d/extension-release.zimaos-login-demo
```

## Generated Raw Layout

```text
/usr/bin/zimaos-login-demo
/usr/lib/systemd/system/zimaos-login-demo.service
/usr/share/casaos/www/modules/zimaos-login-demo/index.html
/usr/share/casaos/www/modules/zimaos-login-demo/logo.svg
/usr/share/casaos/modules/zimaos-login-demo.json
/usr/lib/extension-release.d/extension-release.zimaos-login-demo
```

The module name, raw filename, manifest name, and extension-release suffix are all `zimaos-login-demo`.
